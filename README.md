In this project, we're building a scheduling platform that not only uses Next.js but also integrates with other APIs, like Google and GitHub OAuth APIs, Nylas OAuth API, scheduling APIs, and PostgreSQL as the database with Prisma as the ORM, among many others. I used zod.dev and conform.guide for schema validation and a type-safe library. I took a lot of notes during this project and am eager to discuss them with you face-to-face for a deeper understanding of the project's workflow.

Additionally, I wanted to let you know that for styling, I used both Tailwind CSS and ShadCN UI, but I added a personal touch using "THREE.js" on the main landing page. I incorporated libraries from React, such as react-three/fiber, @react-three/drei, and @react-three/drei/maath, to create it. I deployed the project with Vercel.
